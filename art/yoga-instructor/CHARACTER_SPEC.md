# YogaSenseAI Instructor — Character Spec (master, v1, awaiting approval)

One character, drawn once, reused for every pose. All artwork is generated by
`tools/build_character.py`; poses change **only joint angles**, never the drawings.

## Files
| File | Purpose |
|---|---|
| `instructor_front_rig.svg` | Master front view, neutral A-pose, fully nested rig (import this) |
| `instructor_side_rig.svg` | Master side view (faces right) for Chair Pose |
| `parts/front/*.svg` | Each part separately, pivot at (0,0): head, neck, torso, pelvis, upper_arm, forearm, hand, thigh, shin, foot |
| `parts/side/*.svg` | Side-only variants: head, torso, pelvis, foot (limbs are shared with front) |
| `parts_sheet.svg` | Exploded sheet: coral dot = part pivot, lime dots = where children attach |
| `rig_spec.json` | Hierarchy, segment lengths, local + global pivots, neutral angles, palette |
| `preview/index.html` | Open in a browser to review everything |
| `tools/build_character.py` | Single source of truth; `python build_character.py` regenerates all of the above |

## Design
- Friendly, professional instructor; hair in a top bun; warm medium skin; dark-navy fitted tank and full-length leggings with a thin coral waistband piping (brand accent, no logo); bare feet.
- Clean 2 px outlines, flat fills with one soft horizontal shade gradient per part (stays consistent when parts rotate).
- Proportions ≈ 7.8 heads; full height ≈ 990 units on a 600 × 1080 canvas. Transparent background.
- Palette (fixed): skin `#E2A985`/`#C68A63`, navy `#2B3758`/`#18213A`, hair `#2A1C15`, coral `#FF6B4A` — full list in `rig_spec.json`.

## Skeleton / hierarchy
```
pelvis (root, hip centre)
├── thigh_R ─ shin_R ─ foot_R
├── thigh_L ─ shin_L ─ foot_L
└── torso (waist)
    ├── upper_arm_R ─ forearm_R ─ hand_R
    ├── upper_arm_L ─ forearm_L ─ hand_L
    └── neck ─ head
```
Draw order (front): thighs → pelvis → arms → torso → neck → head. (Thighs and arms sit *behind* pelvis/torso at the joint so no seams show.)
Side view: far arm/leg are tinted darker and drawn behind the body.

## Conventions
- **Angles:** SVG `rotate()` degrees, positive = clockwise on screen. 0 = limb hanging straight down; torso/neck/head 0 = upright. Child angles are relative to the parent.
- **Left/right:** `_L` / `_R` = the instructor's own side. Front view faces the viewer, so `_L` parts are on the viewer's right. To swing a `_L` limb outward use a negative angle; `_R` outward is positive.
- Every rigged `<g>` has `id`, `data-pivot`, and `transform="translate(pivot) rotate(angle)"`; art lives in a child `<g id="…_art">`.

## How to reuse (rules)
1. Never redraw or regenerate the character per pose. Poses = angle sets only.
2. Use the front rig for Tadasana, Tree, Warrior II and Triangle; use the side rig for Chair.
3. Torso is rigid (one piece) and bends only at the waist pivot; side-bends (Triangle) and forward lean (Chair) are torso rotations.
4. Change colours/line style only in `build_character.py` and regenerate everything together.

## Importing into a rigging / animation tool
**Pinkcel:** no application with that name is installed on this PC, and I don't know its import format, so I couldn't check its SVG or rigging support. I haven't operated any external tool. Generic steps that work for most 2D bone-rigging editors:
1. **SVG-capable tools** (e.g. Rive, Moho, Synfig): import `instructor_front_rig.svg`. Each body part arrives as a group named by `id`. Create a bone per part, starting at the pivot in the table above and ending at its child joint. Bind each `*_art` group rigidly to its bone (no mesh deformation needed).
2. **PNG-layer tools** (e.g. Spine, DragonBones, Live2D via PSD): export each file in `parts/front/` and `parts/side/` to a transparent PNG at 4× (e.g. Inkscape: *Export → PNG, 400 % , transparent background*). Each PNG's pivot is the SVG origin (0,0); note its pixel position from the part's `viewBox` (e.g. `upper_arm` viewBox `-35 -30 70 205` → pivot at (35, 30) × scale).
3. Recreate the hierarchy above and set bone origins to the **global pivots** in the table (or `rig_spec.json`).
4. Keep draw order: thighs behind pelvis, arms behind torso, far limbs behind body.
If you tell me which tool you are using (or share its import documentation), I will tailor the export (file format, layer naming, pivot metadata).

## Known limitations (v1)
- Hands use one simplified shape (no individual finger joints); prayer/namaste hands will be an extra hand variant if needed.
- Front-view feet are drawn facing the viewer; turned-out feet (Warrior II / Triangle back foot) may need a ¾ foot variant.
- No facial-expression variants yet.
